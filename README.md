# TAVERN

A premium, cinematic restaurant website built from scratch with modern web technologies.

## Overview

TAVERN is a sophisticated restaurant website focused on:

- Premium visual design
- Cinematic photography
- Elegant typography
- Smooth interactions
- Responsive layouts
- Accessibility
- Performance
- SEO
- Modern React architecture

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Motion
- Lucide React
- Zod
- React Hook Form
