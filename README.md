# Tavern

> **Good Food. Great Vibes. Together.**

A premium restaurant website concept built with Next.js, React, Tailwind CSS, and Motion.

Tavern is designed around a warm, atmospheric dining experience — combining cinematic imagery, editorial typography, subtle motion, and a dark tavern-inspired visual identity.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/tavern.git
cd tavern
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🏗️ Production Build

Create a production build with:


Run the production server locally:


Then open:

## 🎨 Design Philosophy

Tavern was designed to feel less like a traditional restaurant website and more like stepping into the restaurant itself.

The visual direction focuses on:

**Atmosphere**

Warm lighting, dark surfaces, wood tones, and cinematic photography create an intimate environment.

**Typography**

Cormorant Garamond provides an editorial, sophisticated character while Manrope keeps the interface modern and readable.

**Motion**

Animations are intentionally subtle. Page transitions, scroll reveals, and image interactions add depth without overwhelming the content.

**Simplicity**

The interface avoids unnecessary decoration and lets the photography, typography, food, and atmosphere carry the experience.
